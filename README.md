# 🚀 Advanced VPN Client

A fast, secure, and reliable VPN client engineered to bypass the toughest internet restrictions and deep packet inspection (DPI). Works flawlessly in both Europe and Russia/Iran

## ✨ Features
* **Ultimate Censorship Circumvention:** Full support for **VLESS + gRPC + Reality**. It camouflages your traffic as standard web browsing, making it completely invisible to DPI and blocking systems.
* **Privacy First:** Closed-source for security reasons. We strictly do not log, track, store, or sell any of your connection details.
* **Stand-alone Performance:** No third-party tools or extra engines required. Everything works right out of the box.

## 📦 Download
Get the latest APK from the **Releases** section

> ⚠️ **Note on File Size:** The APK is around **80 MB**. This is because the app includes a heavy, high-performance native library: `lib2ray` (Xray core). This embedded core is essential for advanced protocols, ensuring top-tier speeds and unbreakable obfuscation.

## 🛠️ Requirements & Installation
1. Download the APK file.
2. If prompted, enable "Install from Unknown Sources" in your Android settings.
3. Install and launch the app.
4. Import your configuration link (vless://) and click big button on home page.
